# 产品计划

## 产品定位

全国驾培集训与食宿一体化服务平台，面向全国学员集中展示平台认证集训基地，并提供报名、订单、报到、食宿、进度、售后、企业团训和加盟审核流程。

## 用户角色

- 学员：查基地、选班型、报名、看订单、看进度、投诉、退款、评价。
- 基地商户：管理基地、班型、宿舍、食堂、容量、订单和学员进度。
- 区域运营：管理区域基地、订单、投诉退款、企业线索和加盟初审。
- 平台管理员：全平台后台、风控、规则、审核、仲裁和数据看板。

## 核心业务

学员从首页、基地或班型进入报名，平台进行合规确认和风控检测，基地确认容量后生成订单，后续完成报到、入住、用餐、训练进度、投诉退款和评价。

## 业务闭环

流量进入、筛选基地、查看成交页、选择班型、提交报名、创建订单、到校报到、训练跟踪、售后处理、评价沉淀、加盟供给扩展。

## 页面结构

前台包括首页、基地、班型、宿舍、食堂、报名、订单、进度、企业团训、加盟、规则和隐私。后台包括平台、基地和区域运营三类 dashboard。

## MVP 范围

完成可运行、可构建、可部署的 Next.js 应用，包含 Prisma schema、seed、API、mock fallback、权限设计、风控和完整文档。

## P1 路线图

真实认证、支付定金、短信通知、上传资质、地图定位、客服工单、合同签署、后台操作审计落地。

## P2 路线图

加盟评分模型、结算分账、动态容量售卖、企业报价单、BI 报表、风控审核流、商户多账号和多区域运营权限。
